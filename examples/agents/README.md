# Example agent configurations

Copy a Markdown file into `agents/` under **Menu → Open workspace configuration**, or into a repository or global agents directory. These files become available after copying them into a configuration directory.

- **reviewer.md** reviews code with read and search tools.
- **researcher.md** handles a focused research task without automatic project instruction files or skill catalogs.

Both support direct conversations and delegated launches. Model and reasoning settings are inherited unless you add them. See [agent configuration fields and scopes](../../docs/agents.md).
