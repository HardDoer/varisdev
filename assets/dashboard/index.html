            What uses tokens?
            
              
              
                
            • 
                  Input: messages, instructions, tool
                  definitions, skill content, and tool results sent to the
                  model.
                
              • 
                
            • 
                  Output: assistant text and tool arguments,
                  plus reasoning when the provider includes it in usage.
                
              • 
                
            • 
                  Cache: reused or stored input reported by the
                  provider. It still occupies context.
                
              • 
                
            • 
                  No model call: scrolling, selecting a skill,
                  and local tool execution. Tool results can use input tokens on
                  the next call.
                
              • 
              
            
              
            
                Counts use recorded model usage. Providers do not report exact
                tokens for each file, skill, or tool result. Cost estimates use
                configured model rates and may omit Fast or Ultrafast premiums;
                image service billing is separate. Select an agent above to see
                its usage.

              VarisDev keyboard shortcuts
              
        
      
              
      
              
        
              Enter
              
        
              Send a message or steer the running session.
              
        
              Shift + Enter
              
        
              Insert a newline in the composer.
              
        
              Esc
              
        
              
          Stop the selected agent’s running work. When a dialog is open, dismiss
          it instead.
        
              
        
              ↑ / ↓
              
        
              Choose a slash-command suggestion.
              
        
              Tab / Enter
              
        
              
          Complete a partial slash command. Enter sends a complete command.
        
              
        
              ← / →, Home / End
              
        
              Switch tabs when a tab is focused.
              
        
              ⌘/Ctrl + S
              
        
              Save the focused Markdown editor.
              
        
              ⌘/Ctrl + + / − / 0
              
        
              Zoom in, zoom out, or reset zoom.
