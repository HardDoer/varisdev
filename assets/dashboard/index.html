    Your commit agent’s model and reasoning

    The commit agent inherits the parent session’s model and reasoning level by default. Choices saved in Menu → Commit settings override these values.

    The /commit command asks that agent to review changes, create a Git commit and push it to the remote repository.

    Continue sends your command. Configure commit settings keeps it in the composer. Cancel or Escape leaves it unsent.

    Your agents’ model and reasoning

    Background agents inherit the parent session’s model and reasoning level by default. An agent request can explicitly choose another allowed model or reasoning level.

    Choose allowed models in Menu → Agent models. This also limits which models agents can inherit, including agents started by /commit.

          What uses tokens?
          
              
            
                
          • 
                  Input: messages, instructions, tool
                  definitions, skill content, and tool results sent to the
                  model.
                
            • 
                
          • 
                  Output: assistant text and tool arguments,
                  plus reasoning when the provider includes it in usage.
                
            • 
                
          • 
                  Cache: reused or stored input reported by the
                  provider. It still occupies context.
                
            • 
                
          • 
                  No model call: scrolling, selecting a skill,
                  and local tool execution. Tool results can use input tokens on
                  the next call.
                
            • 
              
          
              
          
                Counts use recorded model usage. Providers do not report exact
                tokens for each file, skill, or tool result. Cost uses
                configured model rates; image and audio service billing is
                separate. Select an agent above to see its usage.
